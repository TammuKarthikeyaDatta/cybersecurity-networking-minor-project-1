# Internet request flow diagram

```text
[User enters example.com]
             |
          [Browser]
             |
        [DNS resolution]
             |
     [Destination IP address]
             |
     [PC / Wi-Fi / Switch]
             |
      [Default gateway/router]
             |
          [Internet]
             |
       [Website web server]
             |
       [HTTP(S) response]
             |
     [Browser renders website]
```

DNS resolves the domain name to an IP address. Network routing and transport/application protocols carry the request and response.
